## 🚀 Featured Projects

### 01 · 👁️ Blink-to-Morse Code Converter

A computer vision application that detects eye blinks through a webcam and translates blink patterns into Morse code and readable text.

- Detects eye movements and blink events using facial landmarks.
- Uses blink duration to distinguish dots and dashes.
- Converts detected patterns into Morse code and decoded text.
- Integrates computer vision with an interactive application.

**Tech stack:** Python · OpenCV · MediaPipe · Streamlit

🔗 **[View Project →](https://github.com/Aryan-Devanand-Shinde/EyeBlink_MorseCode)**

---

### 02 · 🌱 Smart Crop Recommendation System

A machine learning application designed to recommend suitable crops using agricultural input features and weather information.

- Uses a trained machine learning model for crop recommendations.
- Integrates weather APIs to incorporate environmental information.
- Provides a web interface for interacting with the prediction system.

**Tech stack:** Python · XGBoost · Pandas · Flask · Weather APIs

🔗 **[View ML Projects →](https://github.com/Aryan-Devanand-Shinde/MINIPRO_ML)**

---

### 03 · 📄 AI-Powered Question Paper Evaluation System

An AI-assisted evaluation system designed to process question papers and student answer sheets, retrieve relevant reference material, and support structured answer evaluation.

**Planned workflow:**

`PDF/Image → OCR & Parsing → Question Structure → Answer Extraction → RAG → AI-Assisted Evaluation`

- Extract questions, marks, options and OR alternatives from question papers.
- Process scanned documents using OCR and vision-capable models.
- Retrieve relevant reference material using embeddings and a vector database.
- Generate structured evaluation results with evidence-based feedback.

**Focus:** Python · OCR · LLMs · RAG · Embeddings · Vector Databases

*An ongoing project and learning direction.*
